# Controle de Despesas

App pessoal de controle de despesas (PWA). Funciona offline e sincroniza com o Google Drive pelo Apps Script.

- Os **dados não ficam neste repositório**: ficam no navegador de cada aparelho e no arquivo `controle-despesas-dados.json` do Google Drive.
- Para conectar: aba **CATEGORIAS E BACKUP** → endereço do app (`/exec`) + código de acesso.
- Para instalar: abrir o site no celular → Safari: Compartilhar → Adicionar à Tela de Início · Chrome: ⋮ → Instalar app / Adicionar à tela inicial.
